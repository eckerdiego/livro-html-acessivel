# Noto Sans local

Coloque nesta pasta os seguintes arquivos, sem renomear:

- `NotoSans-VariableFont_wdth,wght.woff2`
- `NotoSans-Italic-VariableFont_wdth,wght.woff2`
- `OFL.txt`

Finalidade de cada arquivo:

- `NotoSans-VariableFont_wdth,wght.woff2`: fonte variável regular usada pelo corpo e pelos títulos.
- `NotoSans-Italic-VariableFont_wdth,wght.woff2`: variante itálica da fonte variável.
- `OFL.txt`: licença da família tipográfica.

Esta pasta não baixa fontes automaticamente. Os arquivos devem ser adicionados manualmente.
